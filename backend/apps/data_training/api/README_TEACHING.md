# data_training/api 目录教程

- `data_training.py`：训练样例分页、创建、编辑、删除、Excel 导入导出等接口。
- `__init__.py`：包声明。

维护样例时要保证 SQL 与目标数据库方言一致，并只引用该数据源允许的表。

接口包括分页/查询、创建、更新、批量删除、启停和 Excel 导入导出。所有操作按 CurrentUser.oid 隔离，并使用权限/审计装饰器。批量导入可能先跳过 embedding，再集中计算，避免逐行加载模型造成性能问题。

导出用于审阅和迁移，不应导出向量二进制；导入错误应给出行号和原因，而不是整批静默失败。
