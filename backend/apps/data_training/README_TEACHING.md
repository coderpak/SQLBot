# data_training 目录教程

## 作用

维护“自然语言问题 → 正确 SQL”的训练样例。它不是微调模型，而是通过 embedding 找到相似样例，作为 few-shot 上下文塞进 prompt。

- `api/`：样例增删改查、导入导出。
- `curd/`：样例持久化、向量计算、相似检索和 prompt 格式化。
- `models/`：训练样例 SQLModel。
- `__init__.py`：包声明。

## 它解决什么问题

Prompt 的通用 SQL 示例无法覆盖企业特有连接路径、指标公式和方言函数。训练样例把人工确认的正确 SQL 当作运行期 few-shot，让模型模仿“本组织通常怎样回答相似问题”。它不会更新模型参数。

## 数据流

创建/Excel 导入问题与 SQL → 校验工作空间和数据源 → 生成 question embedding → pgvector 保存 → 问数时按相似度/数据源/应用召回 → `to_xml_string` 格式化 → `AiModelQuestion.sql_sys_question` 加入 data_training 段。

## 好样例标准

- 问题自然、明确，不把答案提示写进问题。
- SQL 已在相同数据源验证，使用正确方言。
- 包含真实业务过滤与连接条件，但不包含写操作。
- 一个样例表达一个稳定模式；避免大量仅数值不同的重复样例。
- 表字段变更后及时更新或停用旧样例。

## 与微调的区别

这里的样例可即时增删、能审计、按工作空间隔离、只在相似问题时进入 prompt；微调则修改模型参数且不易解释。对 Text-to-SQL 运维，RAG 样例通常更可控。
