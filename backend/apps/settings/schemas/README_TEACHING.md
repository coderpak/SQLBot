# settings/schemas 目录教程

- `setting_schemas.py`：设置接口的 Pydantic 请求/响应 DTO 与校验规则。
- `__init__.py`：包声明。

Schema 用于限定文件请求或设置输入的合法字段。文件 ID/名称不能直接当磁盘路径；枚举、长度和格式应在 DTO 层先校验，服务层再做真实路径边界检查。

## 输入与输出分离

请求 DTO 只允许客户端需要提交的键；响应 DTO 不返回磁盘绝对路径和敏感配置。下载请求可以传逻辑 file_id，由服务端映射真实路径，而不是接受任意 path。

## 校验策略

拒绝空文件名、路径分隔符、`..`、控制字符和超长值。即使 Pydantic 校验通过，也要在 `resolve()` 后确认目标仍位于 EXCEL_PATH。
