# settings/models 目录教程

- `setting_models.py`：设置项的 SQLModel 持久化结构。
- `__init__.py`：包声明。

若 setting_models 被用于在线配置，应区分 key、value、类型、分组、可编辑性和敏感性。值以字符串/JSON 存储时，读取层负责类型转换；敏感设置不应出现在普通查询响应。当前主要动态参数逻辑仍在 system/parameter。

## 模型层原则

数据库模型负责持久化约束，不应把任意字符串直接当运行配置使用。读取时要按声明类型转换和校验，未知 key 应忽略或拒绝，避免通过数据库配置开启未设计能力。

## 变更注意

新增设置字段要考虑默认值、旧数据迁移、是否热更新、缓存清理和管理权限。配置模型若包含路径，服务层仍需做目录白名单校验。
