# template/generate_predict 目录教程

- `generator.py`：基于历史查询结果做预测时的 prompt 入口。
- `__init__.py`：包声明。

预测输入历史查询数据、字段和上下文，输出预测说明/数据。它是 LLM 辅助推断而非统计模型保证，模板应要求说明依据和不确定性；数据不足时返回不可预测，而不是编造趋势。

## 调用链

用户对已有 record 发起 predict → 后端读取原查询数据/字段 → 组装预测 prompt → 模型流式回答 → 解析/保存 predict_data → `PredictAnswer.vue` 将历史数据与预测数据组合展示。

## 输出契约

预测数据字段必须能与原图表轴对齐，时间或类别值不能随意改变格式。分析文字与结构化预测数据应分开保存。

## 适用边界

适用于简单趋势辅助，不替代统计检验、时序模型和业务决策。没有足够时间点、样本不连续或字段不可解释时应拒绝预测。
