# templates 目录教程

## 文件与目录

- `template.yaml`：通用 prompt 文本：SQL、图表、分析、预测、推荐问题、权限过滤、数据源选择等规则和输出格式。
- `sql_examples/`：按数据库方言维护引用符、LIMIT、函数和示例 SQL。

Python 读取入口是 `apps/template/template.py`，使用 `@cache`；开发中修改 YAML 后通常需要重启或调用 reload。提示词是协议的一部分，改输出格式必须同步解析器和前端。

## 版本管理

Prompt 变化会改变 SQL 质量，应该像代码一样评审并用固定问题集回归。至少记录：简单聚合、多表连接、时间筛选、Top-N、空结果、方言特有函数、行权限和恶意问题。不要只用一两个成功案例判断模板更好。

## 内容安全

Schema、术语、样例和自定义提示词都是动态插入内容，要用明确分隔标签，降低 prompt injection 混入系统规则的风险。模型输出仍必须经过结构和 SQL 安全校验。
